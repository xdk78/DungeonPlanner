# Screenshots

In-game screenshots of Dungeon Planner go here, for the README and the CurseForge page.

Take them in game with `/dp shots` (out of combat; it walks through every view of the window and takes a screenshot of
each, then lists in chat which file shows what; AGENTS.md, "Seeing the UI"). The files land in the game's
`Screenshots` folder, named by time; copy the useful ones here with a name that says what they show, for example
`war-table-deadmines.jpg`, `run-mode.jpg`, `instance-picker.jpg`, `raid-pages.jpg`.

Only real in-game screenshots belong here. The offline renders of `tests/ui_dump.lua` are approximations for checking
layouts and are not product screenshots.
